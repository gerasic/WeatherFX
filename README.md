# WeatherFX

WeatherFX — это JavaFX-приложение, отображающее прогноз погоды с удобным и наглядным интерфейсом.

## Особенности

- Отображение погодных данных в разрезе по времени
- Информация о температуре, ощущаемой температуре, давлении, влажности, скорости ветра и описании погоды
- Поддержка прогноза на несколько дней
- Красивая и отзывчивая графика на JavaFX
